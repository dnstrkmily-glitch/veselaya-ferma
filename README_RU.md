# Весёлая ферма — Android-проект

Это Android-оболочка для HTML-прототипа игры. Животные, интерфейс и заставка включены в приложение, поэтому для самой игры интернет не нужен. Озвучка названий использует системный синтез речи Android и зависит от установленных голосовых данных.

## Что внутри
- `app/src/main/assets/index.html` — игра и список 20 животных.
- `app/src/main/assets/farm-cover.png` — иллюстрация заставки.
- `app/src/main/java/.../MainActivity.java` — экран Android, который открывает игру локально.
- `.github/workflows/build-apk.yml` — автоматическая сборка APK в GitHub Actions.

## Как получить APK, если у вас только телефон
1. В браузере телефона откройте GitHub и войдите в аккаунт или создайте его.
2. Создайте **публичный** новый репозиторий, например `veselaya-ferma`. (В этом проекте нет паролей и личных данных; можно использовать приватный репозиторий, если ваш тариф поддерживает Actions.)
3. Загрузите все файлы и папки из этого архива в корень репозитория, сохранив структуру папок. Удобнее сначала распаковать ZIP в файловом менеджере телефона, затем загрузить файлы через GitHub в браузере. Если интерфейс загрузки папок недоступен на телефоне, можно загрузить ZIP на компьютер позже или воспользоваться GitHub Codespaces.
4. Откройте вкладку **Actions** в репозитории и выберите workflow **Build Android APK**. Нажмите **Run workflow**. При первом запуске GitHub может попросить подтвердить включение Actions.
5. Когда сборка завершится успешно, откройте запуск workflow, прокрутите до **Artifacts** и скачайте `veselaya-ferma-debug-apk`.
6. Распакуйте скачанный архив и откройте `app-debug.apk`. Android может попросить разрешить установку приложений из этого источника. Разрешайте её только для файла, который вы сами собрали в своём репозитории.

## Примечания
- Это **debug APK** для установки и тестирования, не публикационная сборка Google Play.
- Проект не запрашивает интернет-разрешение и не собирает данные.
- Вертикальная ориентация зафиксирована.
- Минимальная версия Android — 6.0 (API 23).
